# Project

This project is a simulation engine for a procedurally generated world. It includes modules for materials, blocks, and procedural generation. The goal is to create a realistic and interactive environment that can be used for various purposes such as education, entertainment, or research.

## Coding standards

 - Use Python 3.11 or later.
 - Follow the PEP 8 style guide for code formatting.
 - Write docstrings for all public classes, methods, and functions.
 - Use type hints where appropriate to improve code readability and maintainability.
 - Keep the codebase clean and organized by following a consistent directory structure.
 - Write unit tests for all new features or bug
 - Adhere to the project's coding standards and guidelines

## Main modules

- **materials**: Defines the materials used in the world, such as stone, wood, and water. Each material has properties like density and resistance that affect how it behaves in the environment.

- **blocks**: Defines the blocks that make up the world. Each block has a name, location, material, states.

- **procedural_worldgen**: Generates the world procedurally based on the materials and blocks defined. This module is currently under development.
